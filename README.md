 Dab’s Beauty Touch (DBT) Website

Dab’s Beauty Touch (DBT) is a beauty business dedicated to boosting confidence
through exceptional hairstyling and personalized client experiences. 
This project showcases a modern, mobile-responsive website built to display services, 
manage appointments, and highlight the DBT brand across different locations.


 Features

- Beautiful landing page with service showcase
- Appointment request form
- Fully responsive design (mobile, tablet, desktop)
- Social media links and brand storytelling


 Built With

- **Frontend**: HTML5, CSS3, JavaScript  
- **Backend**: PHP   
- **Database**: MySQL  
- **Styling**: Bootstrap  
- **Deployment**: Infinity free
